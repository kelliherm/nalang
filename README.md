# Sodium

Sodium is a simple hobby programming language built using C++. It is built loosely following the [LLVM Kaleidoscope Tutorial](https://llvm.org/docs/tutorial/MyFirstLanguageFrontend/index.html) and Robert Nystrom's _Crafting Interpreters_ book.

> [!WARNING]
> Sodium is not a fully functioning programming language. It is not designed for use of any kind outside of playing with programming languages and extreme boredom. This is very much a play at your own risk system.

To compile Sodium:

```bash
g++ *.cpp -o na.exe
```

Programs are run by specifying the file in the command line.

```bash
na.exe file.na
```
